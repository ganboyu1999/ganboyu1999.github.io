数据观测：录制回流；筛选器与取证材料；安全事件与典型跌倒复盘。典型跌倒视频位于 fdi.html#typical-fall-case。

原 fviz-replay.mp4 作为典型跌倒案例仅在数据观测项目中展示，保留素材文件名以维持资源地址。
作品媒体：5 张界面截图、10 段演示视频，视频按需加载，截图可放大查看。
页尾：技术方向、教育背景与版权；不设置底部联系方式。
项目显示名称统一使用中文，不附加英文项目简写。
